# overview.md

## what quire.wiki is

quire.wiki is a digital garden engine. it takes a folder of markdown files and turns it into a published, navigable, interlinked website in the spirit of obsidian publish, quartz, and andy matuschak's notes.

it is for people who think in fragments, link them together over time, and want to share the result publicly without running a cms.

## who it is for

- writers who keep their notes in plain markdown
- researchers building a personal knowledge base
- developers and designers who want a portfolio that grows with their thinking
- anyone tired of the post-as-the-atomic-unit blog model

## what problem it solves

most publishing tools assume you write a finished post and ship it. real thinking does not work that way. ideas evolve. notes link to other notes. some are drafts forever. quire.wiki accepts that.

it gives you:

- a sidebar tree built from your folder structure
- wiki-links between notes, with hover previews
- backlinks computed automatically
- a force-directed graph showing connections
- tags, search, password-protected notes
- light and dark modes
- support for callouts, foldable text, annotations, and mermaid diagrams

## how it feels to use

writing is local. you edit a markdown file, save it, and the site updates. publishing is a deploy. linking is a `[[wiki-link]]` away. the sidebar always shows where you are. the right panel shows connections, tags, and a small graph of the current note.

the design is paper-like in the default theme. warm beige background, serif headings, restrained colors. the dark theme is the same idea inverted. nothing shouts.
