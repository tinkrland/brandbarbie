hashtags are indexing, not decorating — they tell the algorithm where the brand's work lives.

## the core set

- `#brandbarbie` — the house tag, on everything
- `#brandidentity` `#branddesign` `#logodesigner` — the profession tags
- `#smallbusinessbrand` `#femalefounder` — the audience tags (see [[audience & ideal client]])

## usage

- instagram: 3-5 tags, first comment or caption end — never mid-sentence
- x / threads: 0-1 tags; hashtags read as shouting there
- linkedin: none — the algorithm doesn't want them and neither do we

:::note
no tag may exceed 20 characters — past that, nobody types it and the algorithm stops caring (see [[social media]]).
:::
