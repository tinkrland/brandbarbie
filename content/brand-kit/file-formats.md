formats are the language barrier between designers and everyone else. this page translates, so you never have to ask twice.

## the three formats

- **svg** — vector; scales forever, tiny files, editable. the source of truth. use for: web logos, icons, anything going on a plotter or being recolored
- **png** — raster with transparency; fixed pixels. use for: social, slides, anywhere the logo drops onto a photo. get it at 2× the size you need
- **pdf** — vector, print-grade; the file printers actually want. use for: business cards, packaging, anything with crop marks

## the cheat codes

- web → svg first, png fallback
- social → png at 2000px
- print → pdf, cmyk (see [[color codes]])
- sending to a designer → svg, always

:::tip
jpg is for photos only. a logo in a jpg has a white box around it, and now we both know why.
:::
