the library holds every palette the brand may use, each with its own page, its own job, and its own hex codes.

## the stacks

- [[bubblegum core palette]]: the everyday palette; 60/30/10 mapped in [[color ratios]]
- [[noir palette]]: the editorial counterweight for serious moments
- [[soft neutrals palette]]: the supporting cast; backgrounds, papers, buffers

## how to use the library

1. pick **one** palette per project
2. apply [[color ratios]]: a palette is a cast, not a chorus
3. check every text pairing against [[contrast & accessibility]]
4. reference codes from [[color codes]]: never eyedrop from a jpg

:::tip
adding a palette? give it a page, a job, and a season. a palette without a defined job becomes the whole brand's problem.
:::
