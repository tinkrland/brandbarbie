the icon set speaks in one color at a time: restraint is what keeps the set looking expensive.

## the rules

- fill icons are solid single-color: cocoa ink, cream, or bubblegum, one per icon
- outline icons use the same 2px stroke as the system: see [[icon construction]]
- no multi-color icons, no gradients, no shading: a gradient icon is a 2014 app icon

## pairing with color

- on cream: cocoa ink or rose icons; bubblegum only for decorative markers
- on cocoa ink: cream icons only
- on bubblegum backgrounds: cream or cocoa ink, whichever passes contrast: see [[contrast & accessibility]]

## states

- interactive states change weight, not color: hover goes solid, active goes bold
- a colored icon never signals state: color is decorative, weight is functional
