patterns are motifs multiplied. the brand uses them sparingly and loudly.

## pattern types

- **scatter**: motifs tossed across the field, random rotation, even spacing
- **grid**: one motif, tiled; for linings and secondary packaging
- **dense**: pattern as a block of color, used like a solid (tapes, endpapers)

## rules

- patterns use the active palette's background color as their field (see [[palette library]])
- scale to context: packaging pattern is 2-3× the scale of web pattern
- pattern never sits behind body copy: pattern is a surface, not a backdrop
