every rule here exists because someone, somewhere, tried it.

## never

- {hl:pink|stretch, squish, rotate, or add perspective effects}
- recolor outside the approved inversions (see [[backgrounds]])
- set the wordmark in another font
- add drop shadows, outlines, or glows
- crowd it: [[clear space]] is mandatory
- place it on busy photos without a scrim {fold: (why) | text or detail under the mark fights it; use a [[backgrounds]]-approved color or add one}
- use it below [[minimum size]]

:::note
the fix for an awkward placement is always a different variation ([[secondary logo]], [[logomark]], [[monogram]]), never a modified one.
:::
